# Vey — Formally Veyeve®

The source for the Vey website.

## Stack

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Google Fonts (Audiowide)
- Google Analytics 4

No framework, build step, or package manager is required. Serve the repository root with any static web host.

## Local preview

Open `index.html` in a browser, or run a local static HTTP server from this directory.

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Homepage |
| `projects.html` | Project portfolio |
| `about.html` | Team information and principles |
| `contact.html` | Contact page |
| `styles.css` | Shared responsive design, themes, and Vey 95 desktop |
| `script.js` | Navigation, theme controls, quick search, and Easter egg |

The logo and favicon are loaded from the canonical Veyeve website repository.
